# Vevo Catalogs

Static Stremio catalog addon with custom Arabic genre catalogs — movies and series
(كوميديا، فانتازيا، خيال علمي، رومانسي، الأطفال والعائلة، وثائقيات، جريمة، أكشن،
دراما، أعمال مشوقة، واقعي، رسوم متحركة، أنيمي، الجديد والجدير بالمشاهدة).

Install in Stremio from this manifest URL:

```
https://mamimami19.github.io/vevo-catalogs/manifest.json
```

All catalog content comes from the public Cinemeta API
(`v3-cinemeta.strem.io`) — no credentials, no private data. Catalogs are static
snapshots; re-fetch from Cinemeta to refresh them.

---

إضافة قوائم Stremio ثابتة بتصنيفات عربية مخصصة للأفلام والمسلسلات. كل المحتوى
من واجهة Cinemeta العامة — بدون حسابات وبدون بيانات خاصة. للتثبيت في Stremio
انسخ رابط الـ manifest أعلاه.
